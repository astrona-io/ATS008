# Upgrading a Running Kyverno Installation Sandbox

Welcome to the Module 1 targeted practice sandbox. In this lab, you will upgrade an already-running Kyverno Helm release in place, confirm the release revision incremented, and confirm the cluster stayed healthy through the change.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS008.git -c sections/section-060/module-01/labs/lab-01
```
