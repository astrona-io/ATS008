# Kyverno CRDs Capstone

Welcome to the Section 020 Capstone Integration Challenge. In this lab, you will enable `PolicyException` once and author two independent exceptions against two independent policies, proving each is scoped correctly.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS008.git -c sections/section-020/capstone/labs/lab-01
```
