# Controller extraArgs Tuning Sandbox

Welcome to the Module 1 targeted practice sandbox. In this lab, you will use `helm upgrade` to set command-line flags on the background and reports controllers, then confirm both landed on the correct live Deployments.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS008.git -c sections/section-030/module-01/labs/lab-01
```
