# Helm-based Installation and Configuration Capstone

Welcome to the Section 010 Capstone Integration Challenge. In this lab, you will install Kyverno from a values file that combines replica sizing, disabling a controller, and safely extending a list-valued config setting — all three lessons from this section in one install.

## Launching the Lab
Run the following command in your terminal to boot the kind Kubernetes cluster:
```bash
astrona run --git git@github.com:astrona-io/ATS008.git -c sections/section-010/capstone/labs/lab-01
```
